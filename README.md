# 🐶 왈왈왈

인터넷 할 때 **도트 강아지**가 옆에서 응원해주는 크롬 확장이에요.

```
        ####
       #....#          💬 오늘도 잘하고 있어!
      #%%....#
      #%%..@.#
   ####%%....##
  #**********#
  #**#    #**#
```

---

## 🎁 뭐가 되나요?

| | |
|---|---|
| 💬 | 화면 **양옆**에 응원 말풍선이 뿅뿅 떠요 |
| 🐕 | 강아지가 **마우스를 졸졸** 따라와요 |
| 🎤 | **강아지를 클릭**하면 질문 바가 떠요. 말로도 물어볼 수 있어요 |
| ❤️ | 강아지 **쓰다듬으면 하트!** 친해질수록 말이 달라져요 (100단계) |
| ⚠️ | **자동결제** 같은 위험한 버튼을 미리 알려줘요 |
| 😴 | 오래 조용하면 **잠들어요** |
| 📚 | 사이트마다 만든 멘트를 **모아뒀다가 다시 써요** |
| 🎯 | **탭이 많으면** 탭 정리 얘기를 하는 식으로, 상황에 맞춰 말해요 |

## 📥 설치하기 (3분이면 끝!)

### 1️⃣ 파일 받기

이 페이지 위쪽 초록색 **`< > Code`** 버튼 → **`Download ZIP`** 누르기 📦

받은 파일을 **압축 풀기** (오른쪽 클릭 → 압축 풀기)

### 2️⃣ 크롬에 넣기

1. 크롬 주소창에 이거 복사해서 붙여넣기 👇
   ```
   chrome://extensions
   ```
2. 오른쪽 위 **`개발자 모드`** 스위치 켜기 🔛
3. 왼쪽 위 **`압축해제된 확장 프로그램을 로드`** 누르기
4. 아까 압축 푼 폴더 고르기 📂

### 3️⃣ 끝! 🎉

아무 사이트나 들어가 보세요. 강아지가 나와요!

## 🤖 AI 켜기 (선택, 공짜)

이거 안 해도 잘 놀아요. 멘트가 **2952개** 들어있거든요.
켜면 **지금 보는 화면을 읽고** 딱 맞는 말을 해줘요.

1. [build.nvidia.com](https://build.nvidia.com) 접속 → 가입 (무료)
2. `Get API Key` 눌러서 키 복사 (`nvapi-` 로 시작해요)
3. 크롬 오른쪽 위 **🐶 아이콘** 클릭 → 맨 아래 칸에 붙여넣기

> 🔒 키는 **내 컴퓨터에만** 저장돼요. 아무 데도 안 보내요.

## 🎮 사용법

| 하고 싶은 것 | 이렇게 하세요 |
|---|---|
| 질문하기 | **강아지 클릭** → 바로 위에 질문 바가 떠요 |
| 말로 질문하기 | 질문 바에서 🎤 버튼 누르고 말하기 |
| 질문 바 크기 | 바 **양쪽 모서리를 끌면** 폭이 바뀌어요 |
| 대화 이어가기 | 바 아래 글씨를 눌러 **새 대화**로 시작할 수 있어요 |
| 강아지만 숨기기 | 🐶 아이콘 → **강아지 보이기** 끄기 (말풍선은 계속) |
| 전부 끄기 / 켜기 | 🐶 아이콘 → 오른쪽 위 **전원 버튼** |
| 말풍선 줄이기 | 🐶 아이콘 → 수다 빈도를 낮추거나 크기를 60%로 |
| 성격 바꾸기 | 🐶 아이콘 → 말투 4개 중 고르기 |

### 💬 말투 5가지

| 말투 | 이런 느낌 | 말풍선 색 |
|---|---|---|
| 😊 기본 | `오, 평점 좋다!` | 알록달록 캔디색 |
| 😎 커뮤 | `가격 착하네 ㅇㅇ` | 남색 |
| 😤 츤데레 | `별로 안 궁금한데... 평점 높네.` | 하트 무늬 |
| 🎎 선비 | `물건이 실하도다.` | 고동색 |
| 🎲 모두 | 넷이 섞여서 나와요 | 말투마다 다른 색 |

**모두**를 고르면 누가 말했는지 색으로 바로 알 수 있어요.

### 📍 말풍선 위치 (5가지)

설정에서 도트 그림으로 고르면 돼요.

| | 어디에 |
|---|---|
| ◧ | 왼쪽만 |
| ◨ | 오른쪽만 |
| ◫ | 양옆 |
| ▀ | 화면 위쪽 (가로로 흩어짐) |
| ▄ | 화면 아래쪽 (가로로 흩어짐) |

### 📢 말풍선 개수 · 크기

- **개수**: 슬라이더로 0~10개. 0으로 하면 하나도 안 떠요.
- **크기**: 슬라이더로 60~140%. 작게 하면 화면을 덜 가려요.
- **가장자리 여백**: 슬라이더로 0~60px. 0으로 하면 화면 끝에 **딱 붙어요**.

### 🎯 상황 맞춤 멘트

지금 화면 상황을 보고 딱 맞는 말을 골라요.

| 언제 | 이런 말이 나와요 |
|---|---|
| 탭 8개 넘으면 | `탭 정리 좀 할 때 된 듯!` |
| 많이 내렸으면 | `Ctrl+F 로 찾으면 스크롤 안 해도 돼.` |
| 한 곳에 오래 있으면 | `이제 그만 볼때 됨` |
| 마우스 안 움직이면 | `움직임이 없네, 자는 거 아니지?` |
| 글이 길면 | `읽을 게 산더미네.` |
| 영상 보는 중이면 | `영상 보는 중이구나. 방해 안 할게.` |
| 입력창이 많으면 | `중요한 건 먼저 저장.` |

### 📚 멘트 보관함

AI가 사이트마다 만든 멘트를 **주소와 함께 쌓아둬요**.
다음에 같은 사이트에 가면 그걸 다시 꺼내 써서 인터넷을 덜 쓰고 더 빨라요. ⚡

🐶 아이콘 → 맨 아래에서 볼 수 있어요.
- `파일로 저장` : 모은 멘트를 파일로 빼내요 (json)
- `비우기` : 전부 지워요

> 같은 멘트만 계속 나오지 않게, **적게 나온 멘트부터** 뽑아요.
> 그래도 열 번에 세 번은 그냥 랜덤이라 예측이 안 돼요 🎲

## ❓ 자주 묻는 것

**Q. 돈 드나요?**
안 들어요. 전부 공짜예요 💸

**Q. 내 정보 가져가나요?**
AI를 켰을 때만 **페이지 제목이랑 앞부분 조금**을 NVIDIA에 보내요.
비밀번호나 내가 입력한 내용은 **절대 안 보내요.** 걱정되면 AI를 끄면 돼요 🔒

**Q. 마이크가 안 돼요**
`https://` 사이트에서만 돼요. 마이크 버튼을 누르면 크롬이 **허용할지 물어봐요** 🎤
이미 차단해뒀다면 주소창 **왼쪽 자물쇠 → 마이크 → 허용** 으로 풀어주세요.
안 되면 그냥 **타자로 치면** 돼요. 창 아래에 이유를 알려줍니다.

**Q. 확장 아이콘을 눌러도 설정창이 안 떠요**
`chrome://extensions` 안의 카드 말고, **크롬 오른쪽 위 툴바의 🐶 아이콘**을 눌러주세요.
안 보이면 툴바의 🧩 퍼즐 조각을 누르고 왈왈왈 옆 **핀 📌** 을 찍어 고정하세요.

**Q. 강아지가 안 보여요**
🐶 아이콘 눌러서 **전원 버튼**이 켜져 있는지 봐주세요.

**Q. 이전 페이지 말풍선이 계속 떠 있어요**
안 그래요. 페이지를 옮기면 **전부 지우고** 새 페이지 기준으로 다시 띄웁니다 🧹

**Q. 질문했는데 대답이 이상해요**
**짧게** 물어보세요! 대답이 말풍선에 들어가야 하거든요.
`이 사이트 믿을 만해?` 처럼요 👍

## 🛠️ 개발자용

```bash
node test.js      # 파싱·멘트·스프라이트·애정도 검증
```

| 파일 | 하는 일 |
|---|---|
| `content.js` | 말풍선 + 강아지 (모든 페이지에 들어감) |
| `dog.js` | 도트 그림 (걷기·앉기·잠·귀쫑긋·하트·마이크) |
| `lines.js` | 말투별 멘트 2643개(각 620+) + 꿀팁 + 애정도 100개 (총 2952개) |
| `sw.js` | AI 호출, 애정도 계산 |
| `prompts.js` | 말투별 프롬프트 — **말투 추가는 여기부터** |
| `popup.html/js` | 설정 창 |
| `test.html` | 브라우저에서 눈으로 확인하는 페이지 |

말투를 추가하려면 `prompts.js`의 `PERSONA`, `lines.js`의 멘트 풀,
`popup.html`의 버튼에 같은 이름 키를 하나씩 넣으면 돼요.

AI는 NVIDIA NIM(`nemotron-3.5-lightning-30b-a3b`)을 씁니다.
API 호출은 최소 40초 간격 + 페이지별 5분 캐시 + **사이트별 보관함**(호스트당 40줄,
80개 사이트까지)으로 아껴 씁니다. 쿨다운 중에는 보관함에서 꺼내 씁니다.

멘트 선택은 `chrome.storage.local.counts` 에 쌓인 출력 횟수를 보고
**가장 적게 나온 것부터** 고릅니다(30%는 순수 랜덤).

멘트 앞에 접두사를 붙이면 조건이 맞을 때만 뜹니다.
- `8-11|...` 시간대 (8시 이상 11시 미만)
- `@tabs>=8|...` 상황 조건. 쓸 수 있는 키는
  `tabs`(열린 탭 수) `scroll`(스크롤 %) `stay`(머문 초) `idle`(마우스 멈춘 초)
  `long`(본문 글자 수) `video`(영상 재생 중) `forms`(입력창 개수).
  연산자는 `>=` `<=` `>` `<`, 생략하면 "0보다 큼".
  조건이 맞는 멘트가 있으면 65% 확률로 그중에서 고릅니다.
질문 바는 개 위에 붙습니다. 대화 이력은 `sessionStorage` 에 최대 8턴 남고,
`keepChat` 이 켜져 있으면 최근 4턴을 함께 보내 맥락을 잇습니다.
페이지를 옮기면 떠 있던 말풍선과 AI 큐를 모두 버립니다.
